# Changelog

All notable changes to this plugin will be documented here.

## 1.0.1

- The `laxis` MCP server now points at `https://app.laxis.com/mcp` (the web app moved from app.laxis.tech to app.laxis.com). Existing connections keep working; reconnect to pick up the new URL.

## 1.0.0 — initial release

- Added the `laxis` MCP server pointing at `https://app.laxis.tech/mcp`.
- Auth uses OAuth 2.1 with Dynamic Client Registration — no API key or client ID to configure.
- Logo: Laxis's official mark on a white background plate.
